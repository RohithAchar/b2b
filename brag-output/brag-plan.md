# Brag Plan: B2B Wholesale Marketplace

## What is this app?
An Alibaba-style wholesale marketplace for India — search bulk catalog, see ₹ price / unit + MOQ up front, buy from verified suppliers.

## The angle
Wholesale, without the middleman chaos. The video plays it straight and premium: real search terms, real price/MOQ/supplier cards, no generic SaaS fluff. Trust-first trading floor, not a dashboard ad.

## Hook (first 2-3 seconds)
Navy screen. One line slams in: "Wholesale, without the chaos." Orange underline wipes. This earns the next 17s.

## Key moments (the middle)
- The search hero doing its job: "cotton fabric / led lights / jute bags / steel bottles / spices" trending pills popping one by one.
- Product cards with ₹ price, / unit, MOQ, Negotiable badge, verified supplier + city.
- Supplier card + Add action: business name, shield, location, price on request → real price.

## Outro / punchline
"Price. MOQ. Verified supplier. Up front." Logo lockup: B2B MARKETPLACE + orange bar. Hold in silence under music fade.

## User flow worth showing
Search "cotton fabric" → product grid with MOQ/price → product detail with supplier card → add to cart. Entry → key action → result.

## Tone
- Preset: polished
- Creative direction: quiet premium wholesale film, trading-floor confidence
- Interpretation: 4 scenes, long holds (4-6s), soft crossfades, restrained type, generous spacing. Confidence through restraint.

## Format: landscape — 1920x1080
## Duration: 20 seconds

## Visual identity (from the project)
- Background: #F7F8FA (page canvas) / #0A1D3C (navy for hook + outro)
- Accent: #FF6A00 (primary orange), hover #E85F00
- Text: #1B2026 (foreground), secondary #6B7076
- Display font: Inter (fallback DejaVu Sans / Liberation Sans in render)
- Body font: Inter
- Strongest visual element: search hero + product card grid (image → title → bold ₹ price → MOQ → supplier footer with shield)

## Share copy (draft)
Introducing our B2B wholesale marketplace: search the catalog, see ₹ price + MOQ up front, buy from verified suppliers.

Audio-coupled idea: final lockup hit.

Transition mood: hold, end.
